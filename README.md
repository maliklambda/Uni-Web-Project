# Sypher Query Language Visualizer
This project attempts to serve a web interface for visualizing and syntax-checking the IR of the 
[Sypher Query Language](https://github.com/maliklambda/sypher).

## View the hosted Application
The application is hosted publicly on [Render](https://render.com/).
Click here to go to the [deployed version](https://uni-web-technologies-project.onrender.com/).
(Note that there may be startup delay when opening the link. 
This is due to Render's free tier saving on CPU cost.
Should you experience longer waits, feel free to send me an email.)

## Local Development
To run the application locally, follow these steps:
1. Follow the instructions on the [official Rust website](https://rust-lang.org/tools/install/) to download the Rust compiler (and cargo).
2. Use `cargo run .` (or another command to build an executable for your OS) to run the application locally.
3. Open your webbrowser on [localhost:3000](http://localhost:3000) to see the application in action.
